### How did you implement CRUD using SQLite?  
I implemented CRUD using SQLite by creating a database helper class that handles adding, reading, updating, and deleting notes. Each note is saved in a local database so the data stays even after closing the app.  

### What challenges did you face in maintaining data persistence?  
The main challenge I faced was keeping the data consistent after changes and making sure it updates properly on the screen. I also had some issues with managing database connections and ensuring the app didn’t crash when editing or deleting notes.  

### How could you improve performance or UI design in future versions?  
In future versions, I can improve the performance by using background threads for database operations and make the UI better by adding more colors, animations, and smoother layouts.
